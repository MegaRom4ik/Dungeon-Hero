# \# 🏰 Dungeon-Hero

# 

# Консольная ролевая игра на \*\*C++\*\*, в которой игрок управляет героем, исследующим подземелье.

# 

# Во время прохождения герой встречает противников, сражается с ними, получает опыт и становится сильнее. Проект разрабатывается в рамках учебной работы и демонстрирует применение принципов \*\*объектно-ориентированного программирования (ООП)\*\*: работу с классами, объектами и взаимодействием между ними.

# 

# \---

# 

# \## 📖 Описание игры

# 

# Dungeon-Hero — учебный проект, цель которого — показать применение ООП на практике. Игрок управляет персонажем (`Player`), который сражается с монстрами (`Monster`), получает урон, наносит его сам и постепенно развивается.

# 

# \---

# 

# \## ⚔️ Возможности

# 

# В текущей версии проекта реализуются:

# 

# \- создание героя;

# \- характеристики героя:

# &#x20; - имя;

# &#x20; - здоровье;

# &#x20; - урон;

# &#x20; - уровень;

# &#x20; - опыт;

# \- класс `Player` для управления персонажем;

# \- класс `Monster` для создания противников;

# \- система здоровья и урона;

# \- взаимодействие героя с противниками.

# 

# > В дальнейшем функциональность игры будет расширяться.
