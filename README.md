# 🏰 Dungeon-Hero

Консольная ролевая игра на **C++**, в которой игрок управляет героем, исследующим подземелье.

Во время прохождения герой встречает противников, сражается с ними, получает опыт и становится сильнее. Проект разрабатывается в рамках учебной работы и демонстрирует применение принципов **объектно-ориентированного программирования (ООП)**: работу с классами, объектами и взаимодействием между ними.

---

## 📖 Описание игры

Dungeon-Hero — учебный проект, цель которого — показать применение ООП на практике. Игрок управляет персонажем (`Player`), который сражается с монстрами (`Monster`), получает урон, наносит его сам и постепенно развивается.

---

## ⚔️ Возможности

### Базовые

- Создание героя.
- Характеристики героя:
  - имя;
  - здоровье;
  - урон;
  - уровень;
  - опыт.
- Класс `Player` для управления персонажем.
- Класс `Monster` для создания противников.
- Система здоровья и урона.
- Взаимодействие героя с противниками.

### Добавлено

- **Прокачка героя** — получение опыта, повышение уровня, увеличение характеристик.
- **Инвентарь** — предметы, которые герой собирает и использует.
- **Новые монстры** — дополнительные типы противников с разными характеристиками.
- **Система боя** — пошаговая механика сражений между героем и монстрами.

---

## 🏗 Архитектура

| Класс | Назначение |
|---|---|
| `Player` | Управление героем, характеристики, инвентарь, прокачка |
| `Monster` | Противники с характеристиками и поведением |
| `Item` | Предметы в инвентаре *(если реализовано)* |
| `Battle` | Логика пошагового боя *(если реализовано)* |

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <ссылка-на-репозиторий>
cd Dungeon-Hero
```

### 2. Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

### 3. Запуск

```bash
./build/dungeon
```

*(или `build\dungeon.exe` на Windows)*
